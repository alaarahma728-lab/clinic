# 🦷 Prime Smile Dental Clinic

A modern and responsive dental clinic website developed to provide a professional online presence for a dental clinic. The website offers a clean user interface, easy navigation, and an appointment booking experience for patients.

---

## 🚀 Project Overview

This project was built to simulate a real dental clinic website with an attractive design and responsive layout that works across different devices.

---

## ✨ Key Features

- 🏥 Modern and responsive design
- 📅 Appointment booking page
- 👨‍⚕️ Doctors section
- 🦷 Dental services section
- ⭐ Patient testimonials
- 📍 Contact information & location
- 📱 Mobile-friendly interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON Server (for local data)
